# LEMON sources

The files in this folder are the part of LEMON 1.3.1 that minimum-cost matching needs. They come from
the copy bundled with rlemon 0.2.1 (`inst/lemon` at commit `bb193cc4da9f6e7dfbd69450530af341f1314e58`
of https://github.com/cran/rlemon), and they are not edited here. LEMON is distributed under the Boost
Software License 1.0; see `LICENSE`.

That copy is not identical to the LEMON 1.3.1 release. Compared with two other copies,
[The-OpenROAD-Project/lemon-graph](https://github.com/The-OpenROAD-Project/lemon-graph) and
[seqan/lemon](https://github.com/seqan/lemon), rlemon changes these files for newer compilers:

- `lemon/bits/array_map.h`: reformatted, with `std::allocator_traits` written out.
- `lemon/maps.h`: `std::iterator` replaced by iterator type aliases.
- `lemon/math.h`: the constant `PI` commented out.

`lemon/config.h` is generated by rlemon's build. `lemon/matching.h` is identical in all three copies.
The official release could not be reached when this was checked, and the other two copies also carry
their own changes, so this list may not be complete.
