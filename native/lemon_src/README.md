# LEMON sources

The files in this folder are the part of LEMON 1.3.1 that minimum-cost matching needs. They come from
the copy bundled with rlemon 0.2.1 (`inst/lemon` at commit `bb193cc4da9f6e7dfbd69450530af341f1314e58`
of https://github.com/cran/rlemon), and they are not edited here. LEMON is distributed under the Boost
Software License 1.0; see `LICENSE`.

That copy is not identical to the LEMON 1.3.1 release. It was compared with a copy that keeps the
older code in the three files below, found in
[bollenth/lemongraph](https://gitlab.ensta-bretagne.fr/bollenth/lemongraph) (`ext/lemon-1.3.1` at commit
`2184808f42f8657ddcdd685c40550fa458562d55`). Of the 26 files here, 22 are byte-identical to it, and
`LICENSE` is identical too. The others are:

- `lemon/bits/array_map.h`: reformatted, with `std::allocator_traits` in place of the allocator's
  `construct` and `destroy`, which C++20 removes.
- `lemon/maps.h`: `std::iterator`, deprecated in C++17, replaced by iterator type aliases.
- `lemon/math.h`: the constant `PI` commented out.
- `lemon/config.h`: generated by rlemon's build.

None of these changes touches the matching code, and `lemon/matching.h` is identical in every copy
checked, including [The-OpenROAD-Project/lemon-graph](https://github.com/The-OpenROAD-Project/lemon-graph)
and [seqan/lemon](https://github.com/seqan/lemon). The official download could not be reached, so
this comparison rests on these copies and not on the release file itself.
