The shortest walk that covers every street

A postman has to walk down every street of a district and return to the office. Some streets must be walked twice; the question is which ones, so that the extra distance is as small as possible.

This site revisits a 1997 final-year engineering project on this problem, the Chinese Postman Problem, with thirty years of algorithmic progress. Read both reports, run the solver in your browser, or use the code.

The problem

A route that walks every street exactly once and returns to its start exists only when every junction joins an even number of streets: Euler proved this in 1736 for the seven bridges of Königsberg. Real districts have junctions with an odd number of streets, so some streets must be walked again. The Chinese mathematician Kwan Mei-Ko posed the question in 1960: which streets should be repeated so that the extra distance is as small as possible?

The answer pairs up the odd junctions so that the total distance between paired junctions is minimal, repeats the streets along those connections, and then walks the result. Mail delivery, refuse collection, snow ploughing and street sweeping all face this problem every day.

Thirty years later

The 1997 project solved the pairing with a purpose-built branch-and-bound search. The 2026 revision keeps the same method and replaces each stage with what is available today.
