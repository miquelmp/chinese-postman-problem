The shortest walk that covers every street

A postman has to walk down every street of a district and return to the office. Some streets must be walked twice; the question is which ones, so that the extra distance is as small as possible.

This site revisits a 1997 final-year engineering project on this problem, the Chinese Postman Problem, with today's implementations, and follows the paths it left open: streets that need no service, several postmen, vehicles with a capacity. Read both reports, run the solver in your browser, or use the code.

The problem

A route that walks every street exactly once and returns to its start exists only when every junction joins an even number of streets: Euler proved this for the seven bridges of Königsberg, in a paper written in 1735 and published in 1741. Real districts have junctions with an odd number of streets, so some streets must be walked again. The Chinese mathematician Kwan Mei-Ko posed the question in 1960: which streets should be repeated so that the extra distance is as small as possible?

The answer pairs up the odd junctions so that the total distance between paired junctions is minimal, repeats the streets along those connections, and then walks the result. Mail delivery, refuse collection, snow ploughing and street sweeping all build on this problem, usually with added limits such as vehicle capacity or working shifts.

Nearly thirty years later

The method of 1997 is unchanged in outline; each stage now uses what is available today (the polynomial algorithms were already published in 1997; their implementations reach much further), and the paths the project left open are followed up, each with its measured distance from the best known solution.
